## 📖 About The Project

The **Password Strength Checker** is a cybersecurity mini project built using Python.  
It checks whether a password is **Weak**, **Medium**, or **Strong** based on:

✔ Password Length  
✔ Uppercase Letters  
✔ Lowercase Letters  
✔ Numbers  
✔ Special Characters
